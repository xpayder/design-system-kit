# Liquid Glass Reference

The full reference is a community document by Conor Luddy. It has no open-source license, so it is not copied into this plugin — read it from its source:

- Raw text (fetch this): https://raw.githubusercontent.com/conorluddy/LiquidGlassReference/main/README.md
- Repository: https://github.com/conorluddy/LiquidGlassReference

It is written for iOS 26. For the iOS 27 changes and the platform-neutral rules (control layer only, no glass on glass, readability, fallbacks), read `../design-system/references/glass-and-translucency.md` first — often that is enough.

Official sources for exact API behavior: Apple's HIG "Materials" page and the SwiftUI documentation for `glassEffect(_:in:)` and `GlassEffectContainer`.
